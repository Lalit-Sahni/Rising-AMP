# Why there are no folders

Job files are a filing cabinet with labelled drawers, not a hard drive.

Folders are how documents get lost. Two people file the same certificate in two places, someone makes "Docs" next to "Documents", and six months later nobody can find it. That is the same disease as `72 Centenary Drive` / `72 Centenary Road` / `72 Centenary Rd`, which Phase 5 spent a phase curing.

Every file has a job, a type from a fixed list (Contract, Variation, Plan, Permit, Certificate, Quote, Photo, Invoice received, Other), a name, the date on the document, and an optional link to an expense, invoice or HIA contract. Finding a file is search plus a type filter. Neither can be filed wrong.

If folders are revisited it needs a written argument, not a preference. See `PHASE9.md`.
